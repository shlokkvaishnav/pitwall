pitwall

This project finds the hidden battery state and tyre wear of 2026 F1 cars from public timing data. Then it uses them in a race simulator and a pit-strategy agent.

Status: 9 specs are done. The lap model and the undercut model pass. The undercut model also works on 2018 to 2021. The energy regime and two simulator versions fail. The full strategy agent is blocked.

How it works

  1. A gradient-boosting model predicts the next lap time of each car.
  2. A hidden Markov model looks for "push" and "harvest" laps in the errors of the lap model.
  3. A Monte Carlo race simulator gives a probability for each finishing position.
  4. A strategy agent learns pit decisions in the simulator, only if the simulator passes its test.

Results (2026 rounds 4 to 12)

Lap modelPass. Mean error 1.03 s against 1.16 s for the previous lap (11.5% lower, p < 0.0001).
Energy regimeFail. The hidden Markov model is worse than no correction. Its second state is an outlier state, not an energy mode.
Simulator AFail. Spearman 0.72 against 0.79 for the grid order. Podium Brier 0.085 against 0.070.
UndercutPass. A model of the gap, the wait of the rival, the tyre age and the race lap predicts if the undercut works. Log loss 0.56 against 0.69 for the base rate on 2026 (29 duels).
Undercut BMixed. Tyre compounds add nothing, but a new set of tyres helps. A model that uses only data known when the driver pits: Brier skill 0.09 on 2022 to 2025 (p = 0.054, just above the bar) and 0.21 on 2026.
Undercut replicationPass. On 136 duels from 2018 to 2021 that no model saw before, the decision-time model has a Brier skill of 0.12 (p = 0.016).
Simulator BFail. With qualifying pace: Spearman 0.74, Brier 0.079. Better than A, but worse than the grid.

Method

SpecsWe write a spec with pass/fail rules before each run. We keep failed results.
HoldoutThe 2026 races on or after 1 September 2026. The code locks them until the final spec.
This site shows statistics only. Data: the Jolpica-F1 database dump and TracingInsights open data.
